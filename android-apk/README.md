# EASA66 Quiz Android APK

Android WebView wrapper for the live EASA66 Quiz PWA.

The APK loads the HTTPS GitHub Pages application and keeps DOM/local storage available for quiz progress. External links open in the device browser.

## Build
GitHub Actions builds a debug APK automatically when files under `android-apk/` change, or manually from Actions > Build Android APK > Run workflow.

The generated artifact is named **EASA66-Quiz-Android**.
